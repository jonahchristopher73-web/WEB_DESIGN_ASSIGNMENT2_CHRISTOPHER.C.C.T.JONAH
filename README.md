# Carson's Italian Spaghetti

Responsive multi-page website for **Carson's Italian Spaghetti** restaurant.

Built with HTML & CSS for DCOMP 204 – Web Design Assignment 2.

## Pages

- **Home** – Welcome section, popular dishes, opening hours
- **About** – Our story, goals, and meet the team
- **Menu** – Full menu with prices
- **Reservations** – Table booking form
- **Contact** – Phone, email, location and contact form

## Features

- Fully responsive (Mobile, Tablet, Desktop)
- Clean semantic HTML
- Consistent navigation and footer
- Simple Italian-inspired color scheme (deep red + gold)

## How to View

1. Download or clone this repository
2. Open `index.html` in any web browser

## Technologies Used

- HTML5
- CSS3 (Flexbox & Grid)
- Responsive Media Queries
